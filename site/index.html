What is inside

Two ways to make blocks

Proof of work with fork-aware difficulty, or a Clique-style proof of authority where an approved set of signers take turns — the right choice for a group of companies sharing a ledger.

A real ledger

Bitcoin-style UTXO accounting, coinbase maturity, halving schedule, checkpoints, and crash-safe chain reorganisations.

A real network

Peer discovery, header-first sync, reputation and bans, and every message from a peer type-checked before the node looks at it.

A real wallet

12-word recovery phrases, multiple accounts, watch-only wallets, fee bumping, and a light client that verifies proofs itself instead of trusting the node.

Ready to operate

JSON-RPC with authentication, rate limiting and TLS; health and Prometheus metrics; JSON logs; Docker and Kubernetes packaging.

Deliberately left out

Smart contracts, a public token, transaction privacy. It is a ledger, not a platform.

Ten-minute start

git clone https://github.com/behrouzbk/plainchain.git
cd plainchain
npm ci
npm test            # 576 tests, about three minutes
npm run simulate    # three real node processes mine, propagate, and agree

Then follow the hands-on walkthrough: create two wallets, mine, pay, bump a fee, and verify the payment with the light client — every command with its expected output. Three containers with docker compose up; the same mesh on Kubernetes with kubectl apply -k k8s/base.

How it was built

Test-first, with one rule at a time: every consensus or network rule was added together with a test showing the attack it prevents — an inflated coinbase, a forged seal, a double-spend, a peer claiming a block hash it did not earn. The threat model lists about 55 such threats, each pointing at the code that stops it and the test that proves it, plus the risks that are accepted on purpose.

Security status: internally audited with a public threat model; eight findings fixed. No independent security review yet — treat it as pre-audit software and do not put value you cannot afford to lose on a chain built with it. Vulnerabilities: see SECURITY.md.
